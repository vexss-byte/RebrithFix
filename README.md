# Nebula Death Cinema (Fabric, Minecraft 26.3)

## Build
Butuh JDK 25 + Gradle 9.x.
    gradle wrapper      # sekali saja
    ./gradlew build
Hasil: build/libs/nebula-death-cinema-1.0.0.jar

## Pasang
Taruh jar di folder mods SERVER dan CLIENT (+ Fabric API 0.160.5+26.3).
Kamera/kedip/blur jalan di client, jadi player wajib punya mod ini.

## Command (OP)
/matikan <player>   /hidupin <player>   /setwaktu <menit>   /tempatmati
/teskedipan  /tespartikel  /tesorbit  /tesjatuh  /batalnebula
